# EZ BLOT One-Button Wet Transfer Instrument — Practical Handbook

> Technical note on operating the EZ BLOT one-button wet transfer instrument: a three-step workflow (place / turn / press), the details "one-button" cannot replace, and a troubleshooting table. Written as neutral reference documentation.

## TL;DR

- The whole run reduces to three moves: **place** (assemble the sandwich), **turn** (select gel concentration & thickness), **press** (start and wait for the prompt).
- "One-button" covers only parameter setting. You still assemble the sandwich, remove bubbles, cut/activate the membrane, swap the sponge pad, and clean/dry afterward.
- Preset program covers **10–250 kDa** (6/8/10%/gradient gels) and **10–120 kDa** (12/15% gels); custom mode handles anything outside.
- Sponge pad: **single-use recommended** (≤ ~3 reuses).

## 1. Preparations before power-on

### 1.1 Transfer buffer
- One pouch of instrument-specific rapid-transfer buffer premix powder.
- 800 mL deionized water + dissolve; then 200 mL absolute ethanol (anhydrous methanol substitute), mix → 1 L 1× buffer. No pH adjustment.
- No 4 °C pre-cooling; use immediately. Store leftover at 4 °C.

### 1.2 Gel and membrane
- Cut membrane to gel size (oversized membrane → unstable current, edge yellowing).
- Pretreat per membrane instructions (hydrophobic PVDF needs activation).
- Equilibrate gel + activated membrane in buffer. Gloves on; flat-tip forceps for edges only.

### 1.3 Sponge pad
- Soak thoroughly in buffer (complete saturation, even uptake).
- Reused pad: soak to expel internal bubbles; white spots → rinse in DI water, squeeze, re-soak.

## 2. Core three steps: place, turn, press

### Step 1 — Place (sandwich, cathode at bottom)
Tank on level surface; cathode plate at bottom; 55–60 mL buffer in tank.

Assemble cathode → anode:
1. Saturated sponge pad
2. Gel
3. Transfer membrane
4. Saturated sponge pad
5. Anode plate

Roll out air bubbles in one direction with the debubbling roller if needed.

### Step 2 — Turn (gel concentration & thickness)
After module seated + lid closed, turn knob:
- Concentration: 6%–15% (grouped) or gradient gel
- Thickness: 1.0 mm or 1.5 mm

Vertical transfer mode; module lies horizontally, no orientation needed. Keep tank–slot contact stable.

### Step 3 — Press (start)
Press knob to start; screen shows voltage / current / remaining time. Press again to stop (confirm). End → "Transfer complete!" + tone.

## 3. Preset program compatibility range

| Gel group | Molecular-weight range |
|---|---|
| 6% / 8% / 10% / gradient | 10–250 kDa |
| 12% / 15% | 10–120 kDa |

Outside range or special conditions → custom mode (current/voltage/time). Params auto-saved, recallable next run.

## 4. Details "one-button" cannot replace

| # | You still do | Why |
|---|---|---|
| 1 | Assemble sandwich + remove bubbles | Bubble = white ring on band |
| 2 | Cut membrane; activate PVDF; equilibrate | Required for clean transfer |
| 3 | Sponge pad single-use | Reuse → thin, loose, smeared bands (≤ ~3 uses) |
| 4 | Interval between runs | Continuous runs raise temp slightly; wait for thermal control |
| 5 | Clean + dry after transfer | Verify by stain; dry separately or surfaces rust |

## 5. Troubleshooting table

| Symptom | Possible cause | Suggested action |
|---|---|---|
| High temp after transfer | custom params too high/long; consecutive runs | lower params; wait for thermal cycle |
| Marker on gel | MW out of range; weak params; old buffer; wrong consumables; reused sponge | check range; optimize; fresh buffer; dedicated consumables; single-use sponge |
| Membrane edge yellow | membrane too large; high temp | cut to size; see high-temp fix |
| No bands | assembly reversed; PVDF not activated | order sponge–gel–membrane–sponge; activate PVDF |
| White spots/rings | bubbles in sandwich | reassemble / roll out |
| Diffuse/speckled | reused sponge thin | single-use sponge |
| "No current" | module not seated; plate missing | reseat; check anode/cathode |
| Lid loose | not located; debris | align to slot; clean |
| Other | — | Contact manufacturer's local technical support |

## 6. After one experiment

- **Disassemble** anode plate → sponge → membrane → gel → sponge → cathode plate; forceps for membrane edges.
- **Block** immediately in 5% skim milk, rocker, RT 1 h.
- **Dispose** gel + sponge in lab biohazard container.
- **Clean** electrode plates / tank / parts with water; wipe body; **dry fully** before storage. Unused >1 week → clean, power off, disconnect, dry store.

## 7. FAQ

**Touchscreen unresponsive?** Use knob-press; wipe screen + gloves dry (wet gloves/liquid are common causes).

**Rust on plates/tank/slot?** Doesn't affect experiment; dry fully before storage (wet stacking causes rust).

**Sponge reuse count?** Single-use best; if reused, rinse + dry, ≤ ~3 uses, replace if damaged.

**Too much buffer?** Keep in range — excess overflows/contaminates/lowers efficiency; too little → unstable field.
